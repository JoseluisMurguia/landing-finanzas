Módulo 02 // El Backend Lógico

Rentabilidad & Food Cost

El Problema: Los precios de los insumos cambian a diario. Si no costeas con exactitud, la inflación se come tu margen de contribución. Aplicamos lógica paramétrica (FIFO) para auditar tus platillos estrella y evitar fugas ocultas de capital en tiempo real.

Ejecutar Calculadora 5=D
menu_engineering.py 
def calcular_margen_dinamico(receta_id, db_inventario):
    # Calcula el Food Cost usando método FIFO contra inflación
    costo_real = db_inventario.get_fifo_cost(receta_id)
    precio_venta = menu_actual.get_precio(receta_id)
    
    margen_contribucion = precio_venta - costo_real
    
    if (margen_contribucion / precio_venta) < 0.30:
        return "Alerta: Reestructurar Pricing de Platillo"
    return "Rentabilidad Óptima"
